# HelpDesk: Система автоматизации работы IT-службы (1С:Предприятие 8.3)

**Автор:** Севрикеева Виктория Владимировна
**Платформа:** 1С:Предприятие 8.3 (версия 8.3.22.1709)

## 📌 Описание проекта
Данный проект представляет собой автоматизированную систему **«HelpDesk»**, разработанную для оптимизации работы внутренней IT-службы компании. 
Система позволяет сотрудникам регистрировать заявки на устранение неисправностей, а IT-специалистам — брать их в работу, контролировать сроки выполнения и анализировать эффективность своей работы.

## 🎯 Цели и задачи системы
* Регистрация обращений пользователей в единой базе.
* Классификация заявок по категориям, приоритетам и контрольным срокам.
* Автоматическое формирование задач для IT-отдела на основании заявок.
* Распределение задач между исполнителями и отслеживание их статусов.
* Формирование отчетности по просроченным задачам и эффективности сотрудников.

## 🛠 Функциональные возможности (Подсистемы)
Система разделена на логические блоки:
1. **Подсистема «Поддержка»** — доступна обычным сотрудникам. Позволяет создавать документы «ЗаявкаВПоддержку».
2. **Подсистема «Задачи»** — доступна специалистам IT-отдела. Включает в себя:
   * Справочники (Сотрудники, Должности, Подразделения).
   * Документ «ЗадачиITОтдела».
   * Журнал «МоиЗадачи» для удобной работы специалистов.
3. **Отчетность**:
   * Отчет «КонтрольПросроченныхЗадач» (выявление задач с истекшим дедлайном).
   * Отчет «ЭффективностьСотрудников» (анализ количества выполненных задач и задач в работе).

## 🚀 Как развернуть проект (Инструкция)
В репозитории находится **выгрузка информационной базы (файл `.dt`)**.

Чтобы запустить систему на своем компьютере:
1. Установите платформу **1С:Предприятие 8.3** (рекомендуется версия 8.3.22.1709 или новее).
2. Откройте ярлык запуска 1С и нажмите **«Добавить»**.
3. Создайте новую пустую информационную базу (без конфигурации).
4. Запустите созданную базу в режиме **«Конфигуратор»**.
5. В верхнем меню выберите **«Администрирование» -> «Загрузить информационную базу...»**.
6. Выберите файл `.dt` из этого репозитория и дождитесь завершения загрузки.
7. Обновите конфигурацию базы данных (F7) и запустите систему в режиме **«1С:Предприятие»** (F5).

## 👥 Демонстрационные данные
В базе уже настроены тестовые данные для проверки работоспособности (согласно ТЗ):
* Настроены роли и права доступа (Сотрудник, Специалист IT, Руководитель).
* Заполнены справочники (сотрудники, категории обращений).
* Созданы тестовые заявки с разными приоритетами и статусами (включая просроченные).
