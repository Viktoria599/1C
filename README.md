# HelpDesk

Автоматизированная система учета заявок и управления задачами IT-службы на платформе 1С:Предприятие 8.3.

**Автор:** Севрикеева Виктория Владимировна

**Версия платформы:** 8.3.22.1709

## О проекте

Система предназначена для регистрации обращений сотрудников, формирования на их основе задач IT-отдела, контроля сроков выполнения и анализа загрузки специалистов. Включает ролевую модель доступа для сотрудников и специалистов IT-отдела.

## Реализованный функционал

*   **Подсистема "Поддержка":** регистрация обращений документом "ЗаявкаВПоддержку" с автоматическим заполнением автора и проверкой контрольного срока.
*   **Подсистема "Задачи":** ведение справочников (сотрудники, должности, подразделения), работа с документом "ЗадачиITОтдела" и журналом "МоиЗадачи".
*   **Интеграция:** автоматическое создание задачи IT-отдела при проведении заявки с переносом основных реквизитов.
*   **Отчетность:** отчет "КонтрольПросроченныхЗадач" (выявление задач с истекшим сроком) и отчет "ЭффективностьСотрудников" (анализ выполненных задач и задач в работе) + отчет по статусам задач.

## Развертывание

Для запуска системы необходимо использовать выгрузку информационной базы (.dt), приложенную в репозитории.

1. Создайте пустую информационную базу в 1С:Предприятие 8.3.
2. Откройте базу в режиме "Конфигуратор".
3. Выполните команду Администрирование -> Загрузить информационную базу....
4. Выберите файл HelpDesk.dt из данного репозитория.
5. Обновите конфигурацию базы данных (F7).
6. Запустите систему в режиме "1С:Предприятие" (F5).

В базе предварительно заполнены демонстрационные данные (справочники, тестовые заявки с разными статусами и приоритетами) согласно требованиям технического задания.

   # Конфигурация 1С для учёта в торговой компании

Выпускная аттестационная работа по программе «1С-программист» 

**Тема:** «Настройка и разработка простой конфигурации в среде 1С:Предприятие 8.3»

## О проекте

Конфигурация для мультиучёта, которая автоматизирует учёт товаров, услуг и взаиморасчётов с клиентами в торговой компании. Она отражает основные процессы: от заполнения справочников и регистрации цен до оформления продаж и контроля остатков на складе.

## Возможности

- Ведение справочников: Номенклатура, Контрагенты, Организации.
- Оформление продаж товаров и услуг (документы «Реализация товаров» и «Оказание услуг»).
- Регистрация цен документом «Регистрация цен».
- Контроль остатков товаров на складе.
- Отчёты по продажам и остаткам.
- Печатные формы документов.

## Реализованные механизмы

- **Контроль данных при проведении.** Система проверяет статус контрагента и следит за остатками на складе, не допуская отрицательных остатков.
- **Автоматический расчёт.** В документах сами считаются суммы по строкам и итоги, сумма прописью выводится автоматически.
- **Формирование движений по регистрам.** При проведении документов записи создаются в регистрах «Взаиморасчёты», «Продажи» и «Остатки номенклатуры». Товары списываются со склада, услуги нет.
- **Автоматическое ценообразование.** Документ «Регистрация цен» заполняет регистр сведений, и оттуда цены подтягиваются в документы продажи.

## Состав конфигурации

Добавлены и настроены следующие объекты:

- справочники;
- документы;
- печатные формы документов;
- журналы документов;
- регистры сведений;
- регистры накопления;
- подсистемы;
- отчёты;
- стили.


## Как работать с конфигурацией

1. Заполнить базовые справочники (НСИ).
2. Зарегистрировать цены документом «Регистрация цен».
3. Создать документ, например «Реализация товаров».
4. Заполнить.
5. Нажать «Провести и закрыть».
